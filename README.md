# 📊 Datagrid – AI Data Analytics Platform

Datagrid is a modern AI-powered Business Intelligence and Data Analytics platform that enables users to upload datasets or connect databases and instantly generate interactive dashboards, business insights, SQL analytics, AI reports, and Excel dashboards.

Designed for analysts, students, researchers, and businesses, the platform automates data cleaning, profiling, visualization, and reporting while allowing users to interact with their data using natural language through Groq AI.

## 🚀 Key Features

- 📁 Upload CSV, Excel, JSON, TSV, TXT, or ZIP datasets
- 🗄 Connect PostgreSQL, MySQL, and SQLite databases
- 🧹 Automatic data cleaning & preprocessing
- 📈 Interactive BI dashboard with 20+ visualizations
- 📊 KPI cards and business performance metrics
- 📝 AI-powered Executive Summary
- 🤖 Chat with your dataset using Groq AI
- 💬 Natural Language to SQL
- 🔍 SQL query editor with history and favorites
- 📑 Generate HTML, PDF, Markdown & JSON reports
- 📗 Export professional Excel dashboards
- 🌙 Dark/Light mode
- ⚡ Fast Flask backend with responsive UI
